    Glossary¶

    ← Roadmap · README

    One line per term. The goal is that you never nod along to an acronym you don't know. Add a term the moment you meet one you had to look up.

    Term Meaning
    AOT Ahead-Of-Time compilation — native machine code at build time instead of JIT at runtime
    API Application Programming Interface
    APM Application Performance Monitoring
    BFF Backend For Frontend — a gateway shaped for one specific client
    CAP Consistency, Availability, Partition tolerance — pick two under partition
    CI/CD Continuous Integration / Continuous Delivery
    CLR Common Language Runtime — the .NET execution engine
    CLS Common Language Specification — the subset all .NET languages agree on
    CORS Cross-Origin Resource Sharing — browser rules for cross-origin requests
    CQRS Command Query Responsibility Segregation
    CSP Content Security Policy — a header restricting what a page may load
    CSRF / XSRF Cross-Site Request Forgery
    CTS Common Type System
    DDD Domain-Driven Design
    DI Dependency Injection
    DTO Data Transfer Object
    EF Core Entity Framework Core — Microsoft's ORM
    GC Garbage Collector
    gRPC Google Remote Procedure Call — binary RPC over HTTP/2 with protobuf
    HSTS HTTP Strict Transport Security
    IDOR Insecure Direct Object Reference — accessing another user's record by changing an ID
    IL Intermediate Language — what C# compiles to before JIT
    IoC Inversion of Control
    JIT Just-In-Time compilation
    JWT JSON Web Token
    LOH Large Object Heap — objects ≥ 85 KB, not compacted by default
    LTS Long-Term Support — 3-year support .NET releases (even-numbered)
    MVC Model-View-Controller
    OIDC OpenID Connect — an identity layer on top of OAuth 2.0
    ORM Object-Relational Mapper
    OWASP Open Worldwide Application Security Project
    PKCE Proof Key for Code Exchange — protects the auth code flow for public clients
    PII Personally Identifiable Information
    RID Runtime Identifier — e.g. win-x64, linux-musl-arm64
    SSE Server-Sent Events
    SSRF Server-Side Request Forgery
    STS Standard-Term Support — 18-month .NET releases (odd-numbered)
    TFM Target Framework Moniker — e.g. net10.0
    TLS Transport Layer Security
    UoW Unit of Work
    XSS Cross-Site Scripting
    YARP Yet Another Reverse Proxy — Microsoft's .NET reverse proxy library
